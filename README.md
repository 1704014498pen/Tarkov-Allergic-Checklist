# Tarkov Allergic Checklist

Escape from Tarkov의 음식·음료·의료 아이템을 한눈에 보고 **안전/알러지 여부**를 체크하는 단일 HTML 체크리스트입니다. 비공식 팬 제작물입니다.

## 사용법

[stash-ledger.html](stash-ledger.html) 파일을 브라우저로 열면 바로 사용할 수 있습니다. 설치나 빌드 과정은 없습니다.

- 아이템 카드를 **좌클릭**하면 안전 체크(회색 처리)되고 상단 진행률에 반영됩니다.
- 아이템 카드를 **우클릭**하면 알러지 표시(빨간색)가 토글됩니다. 알러지 표시는 **최대 3개**까지이며, 상단에 `알러지 n/3`으로 표시됩니다.
- 두 표시는 동시에 적용되지 않습니다 — 체크된 아이템은 우클릭이, 알러지 아이템은 체크가 무시되며, 먼저 해제해야 전환할 수 있습니다.
- 검색창과 카테고리 칩(음료 / 음식 / 의료키트 / 수술키트 / 붕대·부목·지혈대 / 진통제 / 주사기)으로 필터링할 수 있습니다.
- **초기화** 버튼은 실수 방지를 위해 두 번 눌러야 동작하며, 안전 체크만 지우고 알러지 표시는 유지합니다.

## 데이터

- 수록 항목: 음식·음료 46종, 의료템 43종 (총 89종) — 아이템별 인게임 아이콘 포함
- 체크·알러지 상태는 브라우저 로컬 저장소(localStorage)에만 저장되며 외부로 전송되지 않습니다.
- 아이템 이름과 수치는 게임 위키·커뮤니티 자료 기준으로 정리한 것으로, 패치에 따라 실제 게임과 다를 수 있습니다.

## 라이선스 / 고지

Escape from Tarkov은 Battlestate Games의 상표이며, 아이템 아이콘 이미지의 저작권은 Battlestate Games에 있습니다. 아이콘은 커뮤니티 데이터베이스(tarkov.dev 에셋, SPT 데이터, Escape from Tarkov Wiki)를 통해 비상업적 팬 용도로만 사용했습니다. 이 저장소는 Battlestate Games와 무관한 비공식 팬 제작물입니다.
