# Tarkov Allergic Checklist — 보급품 대장

Escape from Tarkov의 음식·음료·의료 아이템을 한눈에 보고 확보 여부를 체크하는 단일 HTML 체크리스트입니다. 비공식 팬 제작물입니다.

## 사용법

[stash-ledger.html](stash-ledger.html) 파일을 브라우저로 열면 바로 사용할 수 있습니다. 설치나 빌드 과정은 없습니다.

- 아이템 카드를 클릭하면 **확보 완료**로 표시되고 상단 진행률에 반영됩니다.
- 검색창과 카테고리 칩(음료 / 음식 / 의료키트 / 수술키트 / 붕대·부목·지혈대 / 진통제 / 자극제)으로 필터링할 수 있습니다.
- **초기화** 버튼은 실수 방지를 위해 두 번 눌러야 동작합니다.

## 데이터

- 수록 항목: 음식·음료 46종, 의료템 43종 (총 89종)
- 체크 상태는 브라우저 로컬 저장소(localStorage)에만 저장되며 외부로 전송되지 않습니다.
- 아이템 이름과 수치는 게임 위키·커뮤니티 자료 기준으로 정리한 것으로, 패치에 따라 실제 게임과 다를 수 있습니다.

## 라이선스 / 고지

Escape from Tarkov은 Battlestate Games의 상표입니다. 이 저장소는 Battlestate Games와 무관한 비공식 팬 제작물이며, 게임 에셋을 포함하지 않습니다.
